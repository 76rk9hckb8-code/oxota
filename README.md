# Охотзоны — Орловская область

Карта с вашим местоположением по GPS, границами охотничьих зон и работой без интернета.
Работает на iPhone и Android как приложение с экрана «Домой».

## Как запустить (GitHub Pages)

1. Создайте на GitHub новый публичный репозиторий, например `ohotzony`.
2. Загрузите в него все файлы из архива (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/ohotzony/`.

GPS в браузере работает только по https, поэтому нужен именно такой хостинг, а не открытие файла с телефона.

## Установка на телефон

- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Добавить на главный экран».

При первом запуске разрешите доступ к геопозиции.

## Перед поездкой (пока есть интернет)

1. Загрузите границы зон: меню ☰ → «Загрузить файл» (KML, GeoJSON, GPX) или «Нарисовать зону».
2. Откройте район охоты и нажмите «Сохранить видимый район». Большой район сохраняйте частями.
   Если нужен и спутник, переключите подложку кнопкой 🗺️ и сохраните ещё раз.

В лесу GPS работает без интернета, карта берётся из памяти телефона.

## Что показывает

- Вверху: в какой зоне вы стоите, тип зоны и расстояние до её границы. Ближе 200 м — предупреждение.
- При переходе в другую зону — уведомление (и вибрация на Android).
- «Здесь машина» / «Где машина?» — расстояние и направление к машине.
- «Резервная копия зон» — сохранить все зоны в файл GeoJSON (на другой телефон загружается через «Загрузить файл»).

## Откуда взять границы

Официальный источник — Схема размещения, использования и охраны охотничьих угодий
на территории Орловской области (утверждается постановлением Губернатора, к ней прилагается карта).
Границы из файла KML/GeoJSON загружаются сразу. Если есть только карта-схема картинкой,
зоны можно обвести вручную в приложении.

Границы в приложении справочные: в спорных местах у кромки угодья ориентируйтесь на официальную схему и путёвку.
